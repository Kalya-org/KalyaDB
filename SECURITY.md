# Security Policy

KalyaDB is an early-stage project and is not currently suitable for storing important or sensitive data.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. Contact the repository maintainers privately through the security reporting option on the GitHub repository, if available.

Include the affected commit or version, the impact, steps to reproduce in a safe test environment, and any suggested mitigation. Do not include real user data or secrets.

## Current limitations

The engine is not yet implemented. Security guarantees, encryption behaviour, recovery guarantees, and supported threat models have not been established. These will be documented as the implementation develops.
