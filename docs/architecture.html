Platform architecture

Relational engine

The engine owns tables, schemas, typed columns, rows, constraints, relationships, SQL execution, transactions, and the on-disk format. The first relational milestone targets named columns, multiple values per row, and TEXT and INTEGER types.

Service and APIs

A separate service will provide controlled access to the engine through documented APIs. JavaScript/TypeScript and other client libraries will use the same service contracts. The service must validate requests and enforce access rules; database files must never be exposed directly.

Platform services

  • Authentication: user and service identities.
  • Authorization: roles, grants, and row/table-level policies.
  • Realtime: authorized notifications for committed changes.
  • Dashboard: project, table, SQL, API, user, and operations management.

Build order

  1. Relational engine and data integrity.
  2. Transactions, storage recovery, and indexes.
  3. Local database service and documented API.
  4. Authentication, authorization, and SDKs.
  5. Realtime, dashboard, and deployment tools.
