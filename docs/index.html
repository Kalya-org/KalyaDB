A relational database platform,

KalyaDB combines an independent relational engine with a planned service, APIs, authentication, realtime features, and developer dashboard.

Explore the architecture → View source on GitHub ↗
Honest status: KalyaDB is an experimental prototype. The Playground runs an experimental SQL subset locally in your browser; service APIs, authentication, realtime, and the dashboard are planned, not available yet.
THE DESIGN

One relational core. Multiple services.

The engine owns relational data. A service layer and developer tools will build on top of it.

THE FIRST TARGET

Local-first.
Kalya-ready.

KalyaDB is designed to support local use and eventually a separately hosted service. The browser Playground runs a WebAssembly build of the experimental C++ engine and saves data locally in this browser.
