KalyaDB Playground

Write and run relational SQL against the experimental KalyaDB engine compiled to WebAssembly. Commands run locally in this browser.

⚠ Experimental prototype: this playground supports table schemas, multiple columns, TEXT and INTEGER values. The 0.2.0 relational playground uses a fresh browser-local database; earlier prototype data is not migrated. Data is saved in this browser using IndexedDB and normally survives reloads, but clearing browser data or changing browsers/devices can remove or separate it. Do not enter sensitive information.
