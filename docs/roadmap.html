WHAT COMES NEXT

Roadmap

Milestones are only complete when code, tests, and documentation exist. Planned platform features are not available yet.

0.2.0 · Relational core

  • Named columns and table schemas.
  • Multiple values per row.
  • TEXT and INTEGER data types.
  • Type and column-count validation.
  • Structured results with column names.
  • Schema-aware persistence and playground updates.

0.3.x · Relational integrity

  • Primary and foreign keys.
  • Unique, NOT NULL, and NULL constraints.
  • UPDATE, DELETE, filters, and joins.

0.4.x · Reliability

  • Transactions and rollback.
  • Crash recovery and integrity checks.
  • Indexes, backups, and restore.

0.5.x · Database service

  • Local service process and stable engine interface.
  • Documented HTTP API.
  • JavaScript/TypeScript SDK.
  • Kalya desktop integration.

0.6.x · Platform services

  • Authentication and credentials.
  • Roles and authorization policies.
  • Audit logs and realtime events.

0.7.x · Dashboard

  • Project and database management.
  • Table editor and relationship browser.
  • SQL editor, API explorer, users, and policies.

1.0.0 · Production readiness

  • Security and data-integrity review.
  • Documented durability and recovery guarantees.
  • Load, stress, and failure testing.
  • Stable compatibility and deployment policies.
