WHAT COMES NEXT

Roadmap

This is a proposed sequence of milestones, not a release schedule. Items are only complete when implementation, tests, and documentation exist.

01 · Foundation

  • Agree on requirements and non-goals.
  • Choose implementation language and supported platforms.
  • Write down the public API and data model.

02 · Storage prototype

  • Choose and document the on-disk format.
  • Build a disposable storage prototype.
  • Test persistence, restart behaviour, and corruption handling.

03 · Core engine

  • Database creation and opening.
  • Basic reads and writes.
  • Schema/catalog management.
  • Transactions and recovery.

04 · Querying and indexes

  • Select query syntax and implement parsing.
  • Add query execution and validation.
  • Implement indexes and benchmark them.

05 · Kalya integration

  • Define the Electron integration boundary.
  • Test shutdown, concurrent access, and crash recovery.
  • Document backups, restores, and migrations.
